============================================
  NeuralTrade - Windows Setup Guide (Urdu)
============================================

PEHLE YE INSTALL KARO (Sirf Ek Baar):
--------------------------------------

1. Node.js - Download from: https://nodejs.org/
   - LTS version download karo (v20+)
   - Install karte waqt "Add to PATH" checkbox ON rakho

2. VS Code - Download from: https://code.visualstudio.com/


STEP BY STEP SETUP:
-------------------

STEP 1: ZIP ko Extract Karo
- ZIP file ko Desktop par RIGHT CLICK > Extract All karo
- Andar ek folder hoga: neuraltrade-standalone

STEP 2: VS Code Mein Open Karo
- VS Code kholo
- File > Open Folder click karo
- ANDAR WALA neuraltrade-standalone folder select karo
- IMPORTANT: Jisme package.json ho wahi folder select karo!

STEP 3: VS Code Mein Terminal Kholo
- Menu: Terminal > New Terminal
- Ya press karo: Ctrl + ` (backtick key)

STEP 4: Setup Command Chalao
Type karo:
   npm run setup

Ye command automatically:
- npm install karega (packages download)
- prisma generate karega (database client banao)
- prisma db push karega (database banao)

2-3 minute lagega, wait karo!

STEP 5: Start Karo!
Type karo:
   npm run dev

STEP 6: Browser Mein Open Karo
- Chrome kholo
- Type karo: http://localhost:3000
- App dikh jayega!


AGAR KOI ERROR AAYE:
--------------------

Error: "npm is not recognized"
=> Node.js install nahi hua, upar Step 1 follow karo
=> VS Code band karke dobara kholo

Error: "prisma is not recognized"
=> Type karo:
   npx prisma generate
   npx prisma db push

Error: "Port 3000 already in use"
=> Type karo:
   npx kill-port 3000
   npm run dev

Error: "Missing script: setup"
=> Aap GALAT folder mein ho! Andar wala folder select karo
=> Ya type karo:
   npm install
   npx prisma generate
   npx prisma db push

Error: "Module not found: z-ai-web-dev-sdk"
=> Purana ZIP use kar rahe ho, NAYA ZIP download karo

Error: Database connection failed
=> Type karo:
   npx prisma db push --force-reset


QUICK COMMANDS:
---------------
npm run setup    = Sab kuch install + database setup
npm run dev      = Server start karo
npm run build    = Production build banao
npm run start    = Production server chalao
