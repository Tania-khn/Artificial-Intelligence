# 🧠 NeuralTrade AI - Stock Trading Bot

## Quick Start (VS Code)

### 1. Install Node.js
Download from: https://nodejs.org/en/download
→ Windows Installer (.msi) → 64-bit

### 2. Open Project in VS Code
- Extract this ZIP file
- VS Code → File → Open Folder → select extracted folder

### 3. Install Dependencies
```bash
npm install
```

### 4. Setup Database
```bash
npx prisma db push
```

### 5. Start Development Server
```bash
npm run dev
```

### 6. Open in Browser
Go to: http://localhost:3000
