# AI Stock Trading Bot:

The AI Stock Trading Bot is an intelligent web-based application that leverages Artificial Intelligence, Machine Learning, and Reinforcement Learning techniques to analyze stock market data and assist users in making informed trading decisions. The system processes real-time and historical stock data, identifies market trends, and generates actionable BUY, SELL, and HOLD signals.

The platform incorporates advanced technical indicators such as RSI (Relative Strength Index), MACD (Moving Average Convergence Divergence), and Bollinger Bands to enhance market analysis and improve prediction accuracy. A Reinforcement Learning model is trained to learn optimal trading strategies through continuous interaction with market environments, while backtesting functionality allows users to evaluate strategy performance using historical data.

In addition to trading signal generation, the system provides portfolio management, enabling users to track investments, monitor profits and losses, and assess portfolio performance. The project also includes an AI-powered chat assistant that helps users understand market trends, technical indicators, and trading recommendations.

To ensure a safe learning environment, the bot supports automated trading simulation, allowing users to test trading strategies without risking real capital. A real-time notification system keeps users informed about market movements, trading opportunities, and portfolio updates.

## Quick Start (VS Code)

### 1. Install Node.js
Download from: https://nodejs.org/en/download
→ Windows Installer (.msi) → 64-bit

### 2. Open Project in VS Code
- Extract this ZIP file
- VS Code → File → Open Folder → select extracted folder

### 3. Install Dependencies
```bash
npm install
```

### 4. Setup Database
```bash
npx prisma db push
```

### 5. Start Development Server
```bash
npm run dev
```

### 6. Open in Browser
Go to: http://localhost:3000
